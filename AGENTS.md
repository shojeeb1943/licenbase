# LicenBase — AI Agent & Developer Guidelines

This repository uses automated Python generators to compile high-performance, SEO-optimized static HTML pages with zero manual markup drift. All AI coding assistants and developers must adhere to these rules.

---

## 1. Golden Rules for All AI Agents

1. **Never edit generated HTML pages by hand**:
   - Product pages (`*-license.html`) are generated by `generate_pages.py`.
   - Blog posts (`blog/*.html` and `blog/index.html`) are generated by `generate_blog.py`.
   - Company pages (`about.html`, `contact.html`) are generated by `generate_company.py`.
   - Hand-edited HTML files will be overwritten on the next build.
2. **Always publish blog posts via `blog_posts.py` and `python publish_blog.py`**:
   - Adding or updating a blog post is a single-step entry in `blog_posts.py` followed by running `python publish_blog.py`.
   - The publishing command executes validation, page compilation, image rendering, sitemap updates, CSS compilation, and an automated SEO audit.
   - **Zero errors and zero warnings are required** before completing any task.

---

## 3. SEO, Content & Interconnected Linking Standards

Every blog article body MUST satisfy the following content criteria:

1. **Word Count**: Minimum **700 words** (aim for 900–1,400 words for comprehensive technical topics).
2. **Heading Hierarchy**:
   - Starts with a clean lead paragraph (`<p class="text-lg text-gray-600">`).
   - Uses 4 to 9 `<section class="space-y-4">` blocks, each starting with an `<h2 {H2}>`.
   - Never place an `<h1>` inside the body.
3. **In-Article Image / Architecture Diagram**:
   - Provide at least 1 in-article diagram or screenshot saved in `assets/img/blog/<slug>-1.svg` (or `.webp`).
   - Embed using `{figure("<slug>", 1, alt_text, caption, width, height)}`.
   - The feature image (`<slug>-feature.webp`), preview thumbnail (`<slug>-thumb.webp`), and social card (`assets/img/og/blog-<slug>.png`) are rendered automatically.
4. **Mandatory Interconnected Internal Links**:
   - **At least 2 to 3 direct links to commercial product landing pages** (e.g. `<a href="/cpanel-license" {LINK}>cPanel license</a>`, `<a href="/litespeed-license" {LINK}>LiteSpeed</a>`, `<a href="/deals" {LINK}>combo discount stacks</a>`). Never link with `.html` extension.
   - **Contextual cross-links to related blog guides** where relevant.
   - **Links to trust & policy pages** (`/about`, `/contact`, `/license-policy`, `/refund-policy`).
5. **E-E-A-T & Quality Standards**:
   - No fabricated benchmarks, fake reviews, or invented testimonials.
   - Never claim official partnership with vendor trademarks (cPanel, WebPros, LiteSpeed). State that LicenBase provides independent automated IP licensing.
   - Accurate command syntax and genuine documentation references.

## 4. Single-Command Publishing Workflow

To publish or update any blog post:

```bash
# 1. Edit or add the post in blog_posts.py
# 2. Add in-article diagram in assets/img/blog/<slug>-1.svg (if applicable)
# 3. Run the automated publisher:
python publish_blog.py
```

`publish_blog.py` automatically performs:
1. Blog post validation and HTML compilation (`generate_blog.py`).
2. Social OG cards, feature WebPs, and preview thumbnails rendering (`generate_og.py --blog`).
3. Product page guide card cross-links updating (`generate_pages.py`).
4. Google Image sitemap regeneration (`make_sitemap.py`).
5. CSS compilation and minification (`build_css.py`).
6. Full SEO audit across all site pages (`audit_seo.py`).

**If `audit_seo.py` returns any error or warning, fix it immediately and re-run `python publish_blog.py` until 0 errors and 0 warnings are reported.**
