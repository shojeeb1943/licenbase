# LicenBase

**Your Software License Partner**

A professional software licensing and business software marketplace — genuine licenses, subscriptions, hosting, developer tools, security software, and business solutions in one trusted platform.

LicenBase is built to feel like a premium software marketplace and enterprise licensing company — not a key reseller, gaming marketplace, or coupon site.

### Colors

| Role | Hex |
|---|---|
| Primary Blue | `#1E40AF` |
| Dark Navy | `#111827` |
| Accent Emerald | `#10B981` |
| White | `#FFFFFF` |
| Neutral Gray | `#6B7280` |
| Light Background | `#F8FAFC` |

Blue drives CTAs, navigation, and links. Emerald is reserved for positive states only — active, verified, savings, genuine, available. No gradients, no heavy shadows, no glassmorphism.

**Categories:** Operating Systems · Hosting & Infrastructure · Business Software · Developer Tools · Security · Creative Tools

**User journey:** Homepage → Category → Product → License Type → Cart → Checkout → License Delivery

## Design Principles

- Consistent spacing, card radius, and iconography with clear visual hierarchy
- Accessible contrast, polished hover states, realistic ecommerce UI patterns
- No fake logos, statistics, guarantees, or reviews — placeholders only until real data exists
- Responsive: 1440px desktop design (1200–1280px content width, 12-column grid), 2–3 column tablet, single-column mobile

Full design brief: see `licenbase design guide.txt` (not tracked in this repo).
