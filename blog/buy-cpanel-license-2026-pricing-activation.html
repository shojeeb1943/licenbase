VPS Server Hardware and Operating System Requirements

Before issuing your license, ensure your VPS instance meets modern operating system and hardware prerequisites:

  • Operating System: Deploy AlmaLinux 9 64-bit or Ubuntu 22.04 LTS. Both offer active upstream support through 2032 and full compatibility with modern cPanel v120+. Avoid CentOS 7, which reached End-of-Life (EOL) in June 2024.
  • CPU & RAM: While cPanel can technically boot with 2 GB RAM, active production servers handling MySQL queries and email filtering require at least 4 GB to 8 GB RAM and 2 to 4 vCPUs.
  • Storage: Allocate a minimum of 40 GB NVMe or SSD storage. cPanel base installation consumes approximately 6 GB, with the remainder reserved for MariaDB data, system logs, and website backups.
  • Networking: A static, publicly reachable IPv4 address is mandatory. cPanel licenses cannot be registered to private NAT IP addresses or dynamic hostnames.

Step-by-Step cPanel Installation and License Activation

Installing cPanel & WHM on a fresh Linux VPS is completely automated using the official installer:

  1. Log into your server via SSH as the root user.
  2. Set a Fully Qualified Domain Name (FQDN) hostname: 
    hostnamectl set-hostname server.yourdomain.com
  3. Download and execute the official cPanel installation script: 
    cd /home && curl -o latest -L https://securedownloads.cpanel.net/latest && sh latest
  4. Once installation completes (typically 15 to 25 minutes), purchase your automated cPanel license using your server's public IPv4.
  5. Run the single activation command provided in your LicenBase client dashboard, and confirm activation: 
    /usr/local/cpanel/cpkeyclt

The output will confirm Updating cPanel license...Done. Update succeeded. giving you immediate access to WHM on port 2087.
