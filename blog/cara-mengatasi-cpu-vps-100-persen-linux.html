Cara Mengatasi CPU VPS 100%: Tips Linux untuk Admin Server

By LicenBase Team Published October 12, 2026 4 min read

Penggunaan CPU yang menyentuh angka 100% pada server Virtual Private Server (VPS) Linux adalah masalah kritis yang sering dihadapi oleh pengelola server dan agensi web. Ketika prosesor kewalahan, website akan mengalami perlambatan drastis, muncul pesan error 504 Gateway Timeout, antrian database menumpuk, dan akses SSH menjadi tidak responsif. Sebelum Anda memutuskan untuk menambah biaya langganan VPS yang lebih mahal di cloud provider, penting untuk menganalisis proses mana yang menjadi biang keladi dan menerapkan optimasi yang tepat. Dalam panduan lengkap ini, kami membahas langkah-langkah terstruktur untuk menuntaskan masalah lonjakan CPU pada server Linux Anda.

1. Toolkit Diagnosa Cepat: top, htop, dan ps

Segera masuk ke server melalui SSH dan jalankan perintah diagnosa untuk melihat proses yang menghabiskan daya CPU secara riil:

# Tampilkan 10 proses dengan konsumsi CPU tertinggi:
ps aux --sort=-%cpu | head -n 11

# Monitoring interaktif visual:
htop

Di htop, amati apakah beban berasal dari php-fpm, mysqld, atau proses background lain yang tidak dikenal.

2. Menangani Proses PHP-FPM yang Berjalan Liar

Pada server yang meng-hosting website WordPress atau framework PHP, proses php-fpm sering menjadi penyumbang terbesar tingginya CPU:

  • Blokir Serangan xmlrpc.php: Batasi akses ke file xmlrpc.php dan wp-login.php menggunakan rule web server atau Cloudflare WAF.
  • Aktifkan PHP Slow Log: Tambahkan request_slowlog_timeout = 5s pada pool konfigurasi PHP-FPM untuk menemukan script lambat.
  • Sesuaikan pm.max_children: Jangan menyetel nilai terlalu besar yang melebihi kapasitas core dan memori server Anda.

3. Mengatasi Query Database MySQL / MariaDB yang Lambat

Jika proses mysqld memakan CPU tinggi, periksa query yang sedang berjalan:

# Masuk ke MySQL console:
SHOW FULL PROCESSLIST;

# Matikan query yang macet:
KILL <ID_PROSES>;

Aktifkan slow_query_log untuk mengidentifikasi query yang membutuhkan indeks agar tidak melakukan full table scan.

4. Mematikan Proses Zombie dan Cron Job Berat

Script cron job yang berjalan setiap menit tanpa batas waktu eksekusi dapat menumpuk dan menghabiskan CPU. Cari proses zombie dan bersihkan:

# Cari proses zombie:
ps aux | awk '{ print $8 " " $2 }' | grep -w Z

# Jadwalkan backup pada malam hari menggunakan nice:
nice -n 19 ionice -c 3 backup-script.sh

5. Diagnosa Disk I/O Bottleneck dengan iotop

Seringkali CPU 100% bukan disebabkan oleh kalkulasi murni, melainkan tingginya persentase %iowait (CPU menunggu data dibaca dari disk SSD). Pasang dan jalankan iotop -o untuk melihat proses mana yang membanjiri antrian pembacaan disk hard drive.

6. Optimasi Swap Memory dan Nilai Swappiness Linux

Ketika memori RAM fisik server mulai menipis, kernel Linux secara otomatis memindahkan proses yang tidak aktif ke partisi Swap di disk SSD. Namun jika nilai swappiness terlalu tinggi, server akan terlalu agresif menulis ke disk dan menyebabkan lonjakan CPU iowait yang melumpuhkan performa web. Anda dapat memeriksa dan menurunkan nilai swappiness dengan perintah berikut:

# Cek nilai swappiness saat ini:
cat /proc/sys/vm/swappiness

# Atur nilai optimal untuk server web (nilai default biasanya 60, ubah ke 10):
sysctl vm.swappiness=10

# Simpan permanen di /etc/sysctl.conf:
echo "vm.swappiness = 10" >> /etc/sysctl.conf

Pengaturan ini memprioritaskan penggunaan RAM fisik yang jauh lebih cepat daripada disk drive, sehingga beban CPU tetap stabil dan responsif saat lonjakan trafik pengunjung.

6. Tingkatkan Performa dengan LiteSpeed dan CloudLinux

Untuk solusi jangka panjang yang paling efektif, ganti Apache standar dengan lisensi LiteSpeed. LiteSpeed melayani ribuan pengunjung secara bersamaan dengan penggunaan CPU minimal berkat cache LSCache tingkat server.

Jika server Anda melayani banyak klien, tambahkan lisensi CloudLinux untuk membatasi kuota CPU per akun cPanel agar satu website tidak membebani seluruh server. Temukan juga paket bundling murah untuk melengkapi cPanel VPS Anda di LicenBase.
