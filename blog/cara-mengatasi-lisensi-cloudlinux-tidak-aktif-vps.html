Cara Mengatasi Lisensi CloudLinux Tidak Aktif di VPS

By LicenBase Team Published October 14, 2026 4 min read

Bagi pengelola server web hosting, agensi web, dan pemilik VPS di Indonesia, CloudLinux OS adalah fondasi utama untuk menjaga kestabilan server multi-tenant. Dengan fitur Lightweight Virtual Environment (LVE) dan CageFS, CloudLinux mengisolasi setiap akun cPanel agar tidak saling mengganggu penggunaan CPU, RAM, dan I/O disk. Namun, terkadang saat baru memasang atau memperpanjang lisensi murah dari pihak ketiga, administrator menemukan kendala di mana lisensi berstatus "Not Registered", "License Inactive", atau gagal mengunduh pembaruan paket dari repository CloudLinux. Masalah aktivasi ini umumnya terjadi akibat kesalahan konfigurasi jaringan, port firewall yang tertutup, atau ketidaksesuaian IP server. Artikel ini membahas panduan lengkap langkah demi langkah untuk mengatasi lisensi CloudLinux yang tidak aktif pada server VPS Linux Anda.

1. Uji Status Registrasi Resmi dengan `cl-rhn-check`

Langkah diagnostik pertama yang wajib dilakukan adalah memeriksa komunikasi antara server VPS Anda dengan CloudLinux Network (CLN):

# Jalankan perintah verifikasi resmi CLN
cl-rhn-check

# Jika berhasil terdaftar, perintah akan selesai tanpa menampilkan output error

Jika perintah menghasilkan pesan kesalahan seperti "Could not authenticate" atau "Network connection timed out", berarti ada kendala otentikasi IP atau blokir jaringan yang perlu diperbaiki.

2. Pastikan Port Outbound 443 Tidak Diblokir Firewall CSF

Server CloudLinux memverifikasi lisensi melalui protokol HTTPS aman pada port TCP 443. Jika firewall ConfigServer Security & Firewall (CSF) Anda memblokir lalu lintas keluar (outbound), proses verifikasi akan gagal:

# Tes koneksi ke server lisensi resmi
curl -Iv https://cln.cloudlinux.com

# Jika koneksi macet, periksa file /etc/csf/csf.conf
# Pastikan port 443 ada di baris TCP_OUT, lalu restart CSF:
csf -r

Pastikan juga file /etc/resolv.conf menggunakan resolver DNS publik yang stabil seperti 8.8.8.8 dan 1.1.1.1.

3. Samakan Alamat IPv4 Publik Server

Lisensi CloudLinux terikat langsung pada alamat IPv4 primer VPS Anda. Jika server memiliki beberapa IP alias dan lalu lintas keluar menggunakan IP sekunder, server lisensi akan menolak permintaan aktivasi:

# Cek IP publik yang keluar ke internet
curl -4 ifconfig.me

Pastikan IP yang tampil di terminal sama persis dengan IP yang Anda masukkan saat memesan di LicenBase. Jika berbeda, perbarui IP Anda secara gratis di dashboard LicenBase kapan saja.

4. Bersihkan Token Registrasi Lama dan Daftarkan Ulang

Jika sebelumnya server pernah menggunakan lisensi trial atau lisensi dari penyedia lama yang sudah kadaluarsa, file token lama di direktori sistem dapat menghalangi aktivasi lisensi baru:

# Hapus cache sertifikat lama
rm -f /etc/sysconfig/rhn/systemid

# Jalankan ulang skrip aktivasi dari LicenBase atau verifikasi ulang
cl-rhn-check

5. Verifikasi Modul Kernel LVE dan CageFS

Setelah lisensi berhasil terverifikasi, pastikan modul isolasi kernel berjalan aktif dan berfungsi sebagaimana mestinya:

# Cek apakah kernel CloudLinux LVE aktif
uname -r
# Output harus mengandung .lve.

# Cek status proses LVE
lveps -u
