Free .htaccess Rewrite Rule Generator & 10 Redirect Examples

By LicenBase Team Published November 10, 2026 4 min read

The .htaccess configuration file is one of the most powerful utilities available to webmasters running on Apache or LiteSpeed Web Server. From enforcing sitewide HTTPS encryption and standardizing canonical domain structures to routing legacy URLs without losing SEO search equity, mastering mod_rewrite rules is essential. To eliminate syntax errors that trigger 500 Internal Server errors, use our free interactive .htaccess Rewrite Rule Generator alongside these 10 battle-tested redirect patterns.

1. How the .htaccess mod_rewrite Engine Works

The mod_rewrite module uses regular expressions to inspect incoming HTTP request headers and rewrite requested URIs on the fly. Every rewrite block begins with initializing the engine:

RewriteEngine On
RewriteBase /

While Apache evaluates .htaccess files from disk on every single incoming web request, running an accelerated LiteSpeed license caches these rules in memory, delivering up to 8x faster redirect evaluations and lower server CPU utilization.

2. 10 Essential .htaccess Redirect Examples for 2026

Here are the 10 most common, production-tested rewrite snippets used by system administrators and SEO professionals:

1. Force All Traffic to HTTPS (SSL Enforcement)

RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]

2. Force Non-WWW to WWW Canonical

RewriteEngine On
RewriteCond %{HTTP_HOST} ^example\.com [NC]
RewriteRule ^(.*)$ https://www.example.com/$1 [L,R=301]

3. Force WWW to Non-WWW (Apex Domain)

RewriteEngine On
RewriteCond %{HTTP_HOST} ^www\.example\.com [NC]
RewriteRule ^(.*)$ https://example.com/$1 [L,R=301]

4. Redirect an Individual Page to a New URL (301 Permanent)

Redirect 301 /old-service-page /new-service-page

5. Redirect an Entire Folder / Directory Path

RewriteEngine On
RewriteRule ^blog/(.*)$ /articles/$1 [R=301,L]

6. Remove Trailing Slashes from URLs

RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)/$ /$1 [L,R=301]

7. Force Trailing Slashes on Directories

RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_URI} !index
RewriteCond %{REQUEST_URI} !(.*)/$
RewriteRule ^(.*)$ https://%{HTTP_HOST}/$1/ [L,R=301]

8. Redirect Old Domain to New Domain (Domain Migration)

RewriteEngine On
RewriteCond %{HTTP_HOST} ^oldbrand\.com$ [OR]
RewriteCond %{HTTP_HOST} ^www\.oldbrand\.com$
RewriteRule (.*)$ https://www.newbrand.com/$1 [R=301,L]

9. Remove .html Extension from URLs (Clean URLs)

RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_FILENAME}\.html -f
RewriteRule ^(.*)$ $1.html [NC,L]

10. Block Malicious User-Agents and Bad Bots

RewriteEngine On
RewriteCond %{HTTP_USER_AGENT} (SemrushBot|AhrefsBot|DotBot) [NC]
RewriteRule .* - [F,L]
