Install & Activate CloudLinux on cPanel Server: Guide

By LicenBase Team Published October 11, 2026 4 min read

Upgrading your cPanel VPS from standard Linux to CloudLinux OS is the single most effective way to eliminate server crashes caused by abusive client websites. Thanks to CloudLinux's automated conversion tool, you can upgrade a live, production server in under 15 minutes with zero data loss and minimal downtime. Here is the complete step-by-step installation and activation guide in 2026.

1. Step 1: Pre-Installation Checklist and System Verification

Before initiating the conversion, ensure your virtual private server meets the fundamental system requirements:

  • An active cPanel & WHM server running AlmaLinux 8 or 9, CentOS 7, or Rocky Linux.
  • Root SSH terminal access with sudo administrative privileges.
  • At least 4 GB of free disk space on the root filesystem (/) to accommodate new kernel RPMs and CageFS skeleton directories.
  • A registered IP-bound CloudLinux license active on your LicenBase account ($7.00/mo).

It is recommended to take a full server snapshot or run an automated JetBackup cycle before starting major operating system conversions.

2. Step 2: Download and Run the cldeploy Script

Connect to your VPS via SSH as root and download the official CloudLinux conversion utility:

cd /tmp
wget https://repo.cloudlinux.com/cloudlinux/sources/cln/cldeploy
sh cldeploy -i

The script automatically registers your server IP with CloudLinux Network (CLN), replaces standard distribution packages with CloudLinux equivalents, and compiles the LVE-enabled kernel without touching client data or databases. During the conversion process, standard Apache modules, MariaDB libraries, and system utilities are smoothly linked to CloudLinux repositories. The installation log is mirrored to /var/log/cldeploy.log for real-time monitoring and verification.

3. Step 3: Reboot and Verify the LVE Kernel

Once the installer completes with "Complete! System converted successfully", reboot your VPS:

reboot

After the server restarts, verify that the CloudLinux kernel is active:

uname -r

The output will contain .lve., confirming that kernel-level resource boundaries are active.

4. Step 4: Initialize CageFS Virtual Sandboxes

To isolate users and eliminate cross-account symlink traversal attacks, initialize CageFS:

cagefsctl --init
cagefsctl --enable-all

CageFS encapsulates each cPanel user in their own virtualized file system, preventing users from seeing other accounts, system configuration files, or server processes.

5. Step 5: Configure LVE Manager Resource Limits and MySQL Governor

Log into WHM as root and open the LVE Manager interface. Set baseline resource limits across your hosting packages:

  • SPEED: 100% (1 vCPU core). Prevents single sites from saturating multi-core CPUs.
  • PMEM (Physical Memory): 1024 MB. Restricts memory usage per account.
  • IO / IOPS: 20 MB/s and 1024 IOPS. Prevents disk bottlenecks.
  • EP (Entry Processes): 20 concurrent connections. Stops slow script attacks.

To monitor and throttle runaway database queries, initialize MySQL Governor with governor-mysql --install via terminal. MySQL Governor prevents slow, poorly indexed database queries from monopolizing system input/output threads, maintaining sub-second query response times even during heavy concurrent traffic surges across dynamic WordPress e-commerce websites.

6. Summary: Enterprise Multi-Tenant Stability

CloudLinux OS transforms fragile shared hosting servers into robust, multi-tenant cloud platforms. Pair your wholesale CloudLinux license with LiteSpeed Web Server to deliver lightning-fast page loading speeds with 99.99% server stability.
