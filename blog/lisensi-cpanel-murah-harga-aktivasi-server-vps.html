  • Pemutusan Layanan oleh Datacenter: Datacenter lokal Indonesia maupun global seperti Biznet, DCI, IDCloudHost, Hetzner, dan DigitalOcean memblokir IP server yang terdeteksi menjalankan script lisensi bajakan.

Tips Optimasi Server cPanel Setelah Lisensi Aktif

Setelah lisensi cPanel Anda berhasil diaktifkan di VPS, lakukan beberapa langkah optimasi berikut untuk memastikan server berjalan stabil dan cepat:

  • Konfigurasi Tweak Settings di WHM: Batasi alokasi memori default PHP (memory_limit) menjadi 256MB atau 512MB, dan aktifkan kompresi Gzip/Brotli pada web server untuk menghemat bandwidth.
  • Ubah Port SSH Default: Segera ganti port SSH standar 22 ke port acak (misal 2288 atau 4589) untuk mencegah serangan brute-force otomatis dari botnet luar negeri.
  • Pasang CSF Firewall: Gunakan ConfigServer Security & Firewall (CSF) gratis untuk memblokir IP mencurigakan dan membatasi percobaan login yang gagal ke cPanel/WHM.
  • Aktifkan AutoSSL Gratis: Manfaatkan fitur cPanel AutoSSL (Let's Encrypt atau Sectigo) agar seluruh domain klien Anda mendapatkan sertifikat SSL otomatis tanpa biaya tambahan.

Panduan Langkah Aktivasi Lisensi di VPS Linux

  1. Beli lisensi cPanel di LicenBase dengan memasukkan IP publik server Anda.
