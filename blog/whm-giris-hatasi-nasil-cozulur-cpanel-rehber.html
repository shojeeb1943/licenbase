WHM Giriş Hatası Nasıl Çözülür? cPanel Yönetim Rehberi

By LicenBase Team Published October 19, 2026 4 min read

Web hosting yöneticileri ve sunucu sahipleri için WebHost Manager (WHM) paneline erişememek en kritik acil durumlardan biridir. Tarayıcınızda https://SUNUCU_IP:2087 adresine girdiğinizde karşınıza çıkan "Login Failed" veya "Giriş Başarısız" uyarısı, müşteri hesaplarının yönetimini ve acil teknik müdahaleleri tamamen durdurur. Bu teknik rehberimizde, WHM giriş hatalarının nedenlerini, SSH terminali üzerinden cPHulk engellerini kaldırmayı ve acil oturum bağlantısı oluşturmayı adım adım inceliyoruz.

1. WHM Giriş Hatasının Yaygın Nedenleri

WHM oturum açma reddinin arkasında genellikle şu üç temel etken yatar:

  • cPHulk Brute-Force Koruması: Yanlış şifre denemeleri (veya arka plandaki eski şifreli bir e-posta istemcisi) nedeniyle cPHulk IP adresinizi kötü niyetli saldırgan olarak işaretler.
  • Root Parolasının Değişmesi veya Süresinin Dolması: Linux PAM sisteminde root şifresinin süresi dolmuş veya shadow dosyası kilitlenmiş olabilir.
  • cpsrvd Servis Hataları veya Port Blokajı: 2087 SSL portunun CSF/iptables tarafından engellenmesi veya cPanel iç servisinin çökmesi.

Hatanın kaynağını görmek için terminalden cPanel giriş kayıtlarını canlı izleyin:

tail -f /var/log/cpanel/login_log

2. cPHulk Engellerini Terminalden Temizleme

IP adresiniz cPHulk tarafından kilitlendiyse, SSH üzerinden root olarak bağlanın ve şu komutları sırasıyla çalıştırın:

Adım 1: cPHulk engelleme kayıtlarını sıfırlayın

whmapi1 flush_cphulk_logs

Adım 2: Mevcut IP adresinizi kalıcı beyaz listeye (whitelist) ekleyin

Öncelikle curl -4 ifconfig.me komutuyla internet çıkış IP'nizi öğrenin, ardından ekleyin:

whmapi1 cphulk_whitelist_user_ip ip=IP_ADRESINIZ

Komutun ardından The system added the IP address to the whitelist yanıtı belirecektir.

3. Acil Durum Tek Kullanımlık WHM Oturum Linki Üretme

Eğer şifrenizi unuttuysanız veya iki adımlı doğrulama (2FA) kodunuz çalışmıyorsa, terminalden tek bir komutla şifresiz giriş bağlantısı oluşturabilirsiniz:

whmapi1 create_user_session user=root service=whostmgrd app=whostmgr

Terminal ekranında size özel üretilen bağlantı belirecektir:

url: https://sunucu.domaininiz.com:2087/cpsessXXXXXXXX/login/?session=root%3aTOKEN

Bu linki tarayıcınıza yapıştırdığınız anda doğrudan yetkili root kullanıcısı olarak WHM arayüzüne giriş yapabilirsiniz.

4. Root Parolası ve Güvenlik Duvarı Kontrolleri

Linux root parolasını SSH üzerinden güncellemek için:

passwd root

Ardından cPanel yönetim servisini yeniden başlatarak oturum önbelleğini temizleyin:

/scripts/restartsrv_cpsrvd

Eğer bağlantı zaman aşımına uğruyorsa, CSF güvenlik duvarında IP'nizi izinli listeye alın:

csf -a IP_ADRESINIZ
csf -r

5. Güvenlik Duvarı Port İzinleri ve CSF Ayarları

Sunucunuzda ConfigServer Security & Firewall (CSF) kurulu ise, /etc/csf/csf.conf dosyasında gerekli yönetim portlarının açık olduğundan emin olun:

  • TCP_IN ve TCP_OUT Portları: 2082, 2083, 2086, 2087 portlarının listede yer aldığını doğrulayın.
  • Geçici IP Blokajlarını Kaldırma: Şüpheli denemeler nedeniyle engellenen IP adresini kaldırmak için csf -tr IP_ADRESINIZ komutunu kullanın.
  • Sistem Saati Senkronizasyonu: Sunucu sistem saati (NTP) hatalıysa SSL el sıkışmaları başarısız olabilir; chronyc tracking komutuyla zamanı doğrulayın.

6. Gelecekteki Giriş Hatalarını Önleme İpuçları

Sunucunuzda kesintisiz yönetim sağlamak için bu güvenlik önlemlerini alın:

  • WHM > Security Center > cPHulk ayarlarında ofisinizin statik IP adresini kalıcı beyaz listeye kaydedin.
  • Root kullanıcısı için Google Authenticator tabanlı 2FA aktif edin.
  • Standart SSH 22 portunu değiştirerek kaba kuvvet saldırılarının sunucu kaynaklarını tüketmesini engelleyin.
