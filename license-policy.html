1. Genuine Software License Guarantee

LicenBase is committed to uncompromising software authenticity. Every license key, server activation token, and cloud SaaS credential distributed through our marketplace is guaranteed to be 100% authentic, legal, and genuine.

We procure licenses exclusively through authorized direct partner channels, verified enterprise distribution agreements, independent third-party licensing networks, and official vendor APIs. We do not distribute cracked software, gray-market MSDN unauthorized keys, key generators, or nulled scripts.

2. License Models & Classification

Products on LicenBase fall under three distinct operational licensing models:

A

Server IP-Bound Hosting Platform Licenses

Products such as cPanel & WHM, LiteSpeed Web Server, CloudLinux OS, Plesk, WHMCS, Virtualizor, Imunify360, JetBackup, SitePad, and Webuzo. These licenses do not utilize traditional retail text keys. Instead, they are provisioned and synchronized directly to the server's public IPv4/IPv6 address via automated licensing infrastructure and verified registries.

B

Perpetual & Retail Alphanumeric Product Keys

Products such as Windows Server (Standard / Datacenter), Microsoft Windows Pro, Office Professional Plus, and SQL Server. These are delivered as 25-character digital product keys for online or telephone activation on a single device or specified virtual machine instance.

C

Per-User Cloud & Developer Subscriptions

Products such as Microsoft 365 Business Standard, developer IDE licenses, and security cloud consoles. These licenses are bound to authenticated organizational tenant accounts or registered developer email addresses on a monthly/annual subscription basis.

4. Server IP Binding, IP Re-assignment & Migrations

For all IP-bound web hosting licenses (e.g. cPanel, LiteSpeed, CloudLinux, Plesk, WHMCS):

  • Accurate IP Submission: Customers must supply a valid, static, public IPv4 address associated with their VPS or dedicated bare-metal server during checkout.
  • IP Re-assignment / Server Migration: If you migrate your hosting server or change hosting providers, you may update your licensed IP address directly from your LicenBase Customer Dashboard.
  • IP Change Cooldown: To prevent license sharing and distributed abuse across multiple servers simultaneously, IP re-assignments may be subject to a standard 24-hour cooldown between updates.
  • License Verification: You can verify active server license status at any time via official vendor or provider verification tools (such as verify.cpanel.net or provider status checker).

5. Core Allocation & Account Tier Limits

Software licenses must be provisioned in exact alignment with your underlying server hardware and account limits:

  • LiteSpeed Web Server: Licenses are tiered strictly by CPU core count (2-Core, 4-Core, 8-Core, or X-Core Enterprise). Deploying a 2-Core license on a 16-Core bare-metal machine will cause the web server daemon to throttle workers to 2 cores or reject activation.
  • cPanel & WHM: Tiered based on VPS vs Dedicated infrastructure, as well as account bucket limits (Solo, Admin 5 Accounts, Pro 30 Accounts, Premier 100+ Accounts).
  • CloudLinux & Imunify360: Tiered for single-user VPS vs multi-tenant shared hosting servers.

7. Prohibited License Practices & Termination

The following actions violate our License Policy and will result in immediate license cancellation without notice or refund:

  • Sharing single-seat or single-server product keys across multiple non-licensed hardware nodes.
  • Using unauthorized reverse proxy redirection, DNS spoofing, or local key bypasses to circumvent provider licensing servers.
  • Reselling internal or partner licenses on unauthorized third-party marketplaces or forums.
  • Tampering with software licensing binaries, telemetry daemons, or DRM modules.

8. Expiration, Auto-Renewal & Grace Periods

For subscription-based licenses:

  • Automated Renewal: Licenses automatically renew on their recurring cycle (monthly/annual) using your saved payment method to prevent unintended server downtime.
  • Grace Periods: If a renewal payment fails, upstream vendor or provider licensing servers typically allow a 24 to 72-hour grace period before software features (e.g. WHM access, LiteSpeed acceleration) are restricted.
  • Cancellation: You can turn off auto-renewal at any time prior to the billing date from your dashboard. Active licenses remain functional until the end of the paid term. (See Refund Policy: no prorated refunds).
